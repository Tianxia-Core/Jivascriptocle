# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities responsibly via our encrypted disclosure channels rather than public GitHub issues:

- **Encrypted Dispatch Portal**: https://rasaxmachina.com/collins#encrypted-dispatch
- **Trust & RFC 9116 Security Policy**: https://trust.rasaxmachina.com (`https://rasaxmachina.com/.well-known/security.txt`)

We acknowledge verified vulnerability reports within 48 hours and issue coordinated fixes with cryptographic release attestations.
